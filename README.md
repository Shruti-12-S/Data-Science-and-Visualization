# Data-Science-and-Visualization


🚀 **Data Science & Visualization – Hands-on Experiments**

I’m excited to share my series of **hands-on experiments performed using Google Colab** as part of my **Data Science and Visualization** coursework.
These experiments focus on building strong fundamentals in **data analysis, visualization, and machine learning** using Python.

🔬 **List of Experiments Covered:**

1️⃣ **Introduction to Jupyter Notebook & Python Basics**

• Setup using Anaconda

• Python programs on data types, loops, and functions

2️⃣ **Working with Public Datasets**

• Loading and exploring datasets from **Kaggle** and **UCI** using Pandas

3️⃣ **Data Cleaning & Handling Missing Values**

• Null value treatment, outlier removal, and duplicate detection

4️⃣ **Data Transformation & Feature Engineering**

• Standardization, normalization, and encoding using **Pandas** and **Scikit-learn**

5️⃣ **Exploratory Data Analysis (EDA) – Descriptive Statistics**

• Summary statistics, correlation analysis, and group-wise aggregations

6️⃣ **Data Visualization – Univariate Analysis**

• Histograms, boxplots, and bar charts using **Matplotlib** and **Seaborn**

7️⃣ **Data Visualization – Multivariate Analysis**

• Scatter plots, heatmaps, pair plots, and relationship analysis

8️⃣ **Supervised Learning – Linear Regression**

• Model implementation and performance evaluation

9️⃣ **Supervised Learning – Logistic Regression & k-NN**

• Classification models with evaluation using accuracy, precision, and recall

🔟 **Unsupervised Learning – k-Means Clustering & PCA**

• Clustering visualization and dimensionality reduction using PCA
